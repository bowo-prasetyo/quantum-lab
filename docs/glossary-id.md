# Glosarium: English → Bahasa Indonesia

The terms used in the Indonesian translation (`locales/id.js`,
`content/id.js`), so every page says the same thing the same way. A
reviewer who changes a term here should change it in both files.

Style: plain, friendly Indonesian for a beginner, addressing the learner as
*Anda*. Standard terms from Indonesian physics teaching where they exist
(*superposisi*, *amplitudo*, *fase*); loanwords kept where Indonesian
physics usage keeps them (*qubit*, *shot*). Quantum notation, gate names
(H, X, CNOT…) and *Glass Qubit* are not translated.
